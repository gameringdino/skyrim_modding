# Custom Skyrim Modlist Blueprint

## Overview
This blueprint outlines the custom modlist configuration, load order structure, and optimization pipeline for Skyrim Special Edition running under Kubuntu Linux with Proton 9.0 and Mod Organizer 2.

## Installed Mods & Tools
1. **SkyUI** - Modern user interface extension.
2. **SSE Engine Fixes** - Core engine bug fixes and stability improvements.
3. **PapyrusUtil SE** - Scripting utility functions.
4. **SSE Display Tweaks** - Framerate and display enhancements.
5. **Address Library for SKSE Plugins** - Essential runtime dependency for SKSE native plugins.
6. **Lydia Re-Created** - Visual overhaul for Lydia.
7. **Improved Dragonfly** - High-resolution creature textures.
8. **Unskippable Dialogue NG** - Dialogue system enhancements.
9. **Majestic Mountains** - Landscape texture overhaul.
10. **BodySlide and Outfit Studio** - Custom body physics and armor fitting.
11. **Cathedral Assets Optimizer (CAO)** - Texture and mesh asset optimization pipeline.
12. **SSEEdit** - Conflict resolution and plugin cleaning.
13. **LOOT** - Load order optimization.
14. **Wrye Bash** - Bashed patch generation.

## Execution & Deployment Pipeline
- Managed via Mod Organizer 2 (`/run/media/timothy/5b91fdfe-bc58-477e-9bc4-bae46ef82aa2/skyrim_modding/MO2/ModOrganizer.exe`).
- Launched using Proton 9.0 compatibility layer wrapper script [`launch_mo2.sh`](/run/media/timothy/5b91fdfe-bc58-477e-9bc4-bae46ef82aa2/skyrim_modding/MO2/launch_mo2.sh).
